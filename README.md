# Lyktan — 스웨덴어 대화 드라마 기획

스톡홀름 쇠데르말름의 작은 서점 **Lyktan**에서 우연히 만난 번역가 린네아와 목선 목수 오스카르가
사계절을 지나며 사랑에 빠지는 과정을 담은 **스웨덴어 학습용 대화 드라마**입니다.

- **분량** 4부 × 14화 × 120턴 = 56화, 6,720턴
- **수준** A1~B2를 한 화 안에서 섞고, 모든 턴에 레벨 태그
- **형식** 스웨덴어 대사 + 한국어 번역 + 화별 핵심 표현·문화 메모

## 작업 방식
- 원고: `src/pX_eYY.txt` (화자|레벨|스웨덴어|한국어) → `python3 tools/build_episode.py src/*.txt` 로 `episodes/*.md` 생성·검증
  (120턴, 같은 화자 연속 금지, 부별 레벨 분포 ±6)
- 설정 연속성: [`notes/continuity.md`](notes/continuity.md)
