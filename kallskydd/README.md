# Källskydd — 스웨덴어 대화 드라마 기획 (탐사보도 스릴러)

스톡홀름 일간지 **Stockholmsposten**의 지하 탐사보도팀 **"Källaren"**.
기자 **빅토르 홀름**과 팀이 갱단 청부, 복지 사기, 그림자 선단, 녹색 전환, 트롤 공장, 내부 첩자,
그리고 그 모두를 잇는 네트워크 **"Klubben"**을 파헤치며 진실을 세상에 드러내는 **스웨덴어 학습용 대화 드라마**.

- **분량** 7부 × 15화 × 150턴 = 105화, 15,750턴
- **시간** 2025년 10월 → 2026년 9월 총선 → 2027년 4월
- **수준** A1~B2 혼합, 모든 턴에 레벨 태그 (부가 진행될수록 B1·B2 상승)
- **형식** 스웨덴어 대사 + 한국어 번역 + 화별 핵심 표현·저널리즘/법 메모
- 모든 인물·기업·정당·언론사는 가상. 스웨덴 2021~2026 현안은 배경으로만 사용.
